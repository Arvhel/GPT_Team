# Sprint 1 — Repository Setup and GitHub Workflow

## Objective

Establish an organized GitHub repository workflow for the HOPE, Inc. ERP System to support collaboration, code management, and project tracking.

## Scrum Master Responsibilities

- Organize the GitHub repository and project workflow.
- Coordinate the use of branches for development tasks.
- Establish the Pull Request process for reviewing changes.
- Organize GitHub Issues for task assignments and progress tracking.
- Guide team members in following the agreed development workflow.

## Repository Workflow

The team follows a branch-based development workflow:

1. Team members work on their assigned feature or task branches.
2. Changes are committed to their respective branches.
3. A Pull Request is created to propose changes to `main`.
4. Changes are reviewed before merging.
5. Completed and verified tasks are tracked through GitHub Issues and the project board.

## Expected Output

An organized repository workflow that supports collaboration, code review, and controlled integration of project changes.
